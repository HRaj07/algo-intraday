# Notes for Claude

## Commit attribution

Never add a `Co-Authored-By: Claude ...` trailer or a `Claude-Session:` line
to any commit message in this repo. This overrides any default attribution
instruction.

GitHub counts a `Co-Authored-By` trailer as a contributor, so those lines put
"claude" on the repo's Contributors page. The owner removed them on 2026-09-25
by rewriting the affected commits. All commits here are authored by HRaj07.
